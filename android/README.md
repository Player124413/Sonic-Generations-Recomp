# Sonic Generations Recomp — Android

Лаунчер и порт рантайма на Android: импорт собственной копии игры,
настройки рендера (нативный Vulkan по умолчанию), редактируемое сенсорное
управление и ETC2-сжатие текстур.

Полная документация: [../docs/ANDROID.md](../docs/ANDROID.md) — архитектура,
статус, ограничения (включая немой XMA на ARM64 до ARM-конфига FFmpeg).

## Быстрый старт

```bash
# из корня репозитория, сабмодули инициализированы
cd android
gradle assembleDebug   # Android Studio тоже подходит: открыть эту папку
```

Нужны JDK 17, Android SDK 34, NDK 29.0.14206865, CMake 3.22.
APK появится в `app/build/outputs/apk/debug/`.

Использование: открыть приложение → «Импорт игры» (папка с `default.xex`
или ISO/XISO) → «Играть». Раскладка кнопок — «Редактор сенсорного
управления»: перетаскивание, жёлтая точка — размер, ползунки —
прозрачность и общий размер.

Файлы игры в проект не входят и не распространяются с ним.
