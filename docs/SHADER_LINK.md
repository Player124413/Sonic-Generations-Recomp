# Передача ссылки на шейдеры агенту

Можно прислать агенту прямую HTTPS-ссылку на `shaders.zip` и попросить
подготовить запуск. Лучше использовать временную ссылку только на один файл.
Не присылайте пароли, GitHub-токены или ключи доступа к хранилищу.
Ссылка останется в истории чата: если это нежелательно, самостоятельно задайте
`SHADERS_ZIP_URL` в Settings → Secrets and variables → Actions.

Помощник `scripts/prepare_shader_link.py`:

- получает ссылку через stdin, а не аргумент командной строки;
- скачивает поток без сохранения игровых ресурсов на диск (до 256 MiB);
- проверяет HTTPS, сигнатуру ZIP и вычисляет SHA-256;
- сохраняет URL в GitHub Actions secret `SHADERS_ZIP_URL` текущего репозитория
  через уже авторизованный `gh`;
- выводит SHA-256 для workflow, но не сам URL.

Запуск из корня репозитория: `python scripts/prepare_shader_link.py`, затем
передать ссылку одной строкой на stdin. Не сохраняйте её в файлы репозитория.
Скрипт меняет секрет, но **не запускает workflow**, не загружает artifacts и
не публикует игровые данные. Проверка сигнатуры не заменяет проверку ZIP
конвертером. Вычисленный SHA-256 фиксирует скачанные байты, но не подтверждает
подлинность источника.

Для запуска конвертации workflow должен существовать на GitHub и иметь
`workflow_dispatch`. В текущем checkout `.github/workflows/shaders.yml`
отсутствует: помощник не создаёт его и не заменяет конвертер.
