# Полный список импортов из пользовательского аудита

Источник — присланный пользователем полный вывод `Import audit v1`:

- размер XEX: **8 773 632 байта**;
- XXH64: **BC88D51CE0755637** (не криптографическая идентификация);
- **231 импорт: 219 функций и 12 переменных**;
- все 219 функций уже успешно привязались;
- отсутствовали ровно три переменные: 0x158, 0x156, 0x1AE.

Фактическая версия бинарного файла и его SHA256 из этих метаданных не следуют.
Файлы игры не сохранены в репозитории. `tests/fixtures/observed_title_imports.json`
и `.inc` содержат только метаданные: library, ordinal, имя, тип, IAT и thunk.
Функции дополнительно сверены с существующим compiled inventory. Адреса
выделенных рантаймом объектов из лога не являются ABI-константами и не сохранены.

## Переменные, требуемые именно этим образом

| Ordinal | Имя | IAT |
|---|---|---|
| 0x1C0 | VdGpuClockInMHz | 0x82000520 |
| 0x1C1 | VdHSIOCalibrationLock | 0x82000540 |
| 0x158 | XboxKrnlVersion | 0x82000560 |
| 0x266 | KeCertMonitorData | 0x820005B8 |
| 0x1BF | VdGlobalXamDevice | 0x820005C0 |
| 0x1BE | VdGlobalDevice | 0x820005C4 |
| 0x156 | XboxHardwareInfo | 0x820005E8 |
| 0x193 | XexExecutableModuleHandle | 0x820005EC |
| 0x1AE | ExLoadedCommandLine | 0x820005FC |
| 0x1B | ExThreadObjectType | 0x8200060C |
| 0xAD | KeTimeStampBundle | 0x82000760 |
| 0x59 | KeDebugMonitorData | 0x82000770 |

ExEventObjectType / ExSemaphoreObjectType также реализованы, но этот образ их
не импортирует. Реестр реализованных экспортов не надо путать со списком
импортов конкретной игры.

## Реализация трёх недостающих экспортов

Сверка структуры и политики начальных значений:
[Xenia xboxkrnl_module.cc](https://github.com/xenia-project/xenia/blob/master/src/xenia/kernel/xboxkrnl/xboxkrnl_module.cc).

- **XboxKrnlVersion:** прямой адрес 8 байт `00 02 FF FF FF FF 80 00`.
  Это совместимая с Xenia HLE-политика версии, а не утверждение о запуске
  настоящего retail kernel. Версия состоит из BE16 полей и последних байтов
  QFE/flags; не используется версия Windows.
- **XboxHardwareInfo:** прямой адрес 16-байтовой структуры: BE32 flags `0x20`,
  logical CPU count `6` по смещению 4, остальные 11 байт нулевые. Это гостевая
  политика инициализированного хранилища и Xbox CPU, не описание ПК пользователя.
- **ExLoadedCommandLine:** прямой адрес записываемого ANSI-буфера 1024 байта со
  строкой `"default.xex"` и NUL. Это **не адрес указателя** и не UTF-16.
  Параметры хостового диагностического запуска туда не передаются.

Объекты выделяются в гостевой памяти один раз. Повторная регистрация образа
не меняет их адреса и не сбрасывает записываемый command-line buffer.

## Общая регрессионная проверка

`TestObservedTitleImports` создаёт синтетический XEX import directory с обеими
библиотеками и всеми 231 записями из отчёта одновременно. Тела игры не нужны.
Проверяет полный dry-run без IAT-записей, успешную привязку всех функций и
переменных, формат/начальные байты трёх новых объектов, стабильность адресов,
запись строки и атомарный отказ при неподдержанном последнем импорте.
Отдельный Python-тест сверяет JSON, C++ fixture, количество и IAT-диапазоны,
а все функции — с compiled inventory. Проверки включены в CTest/CI.

Это закрывает три обнаруженных пропуска привязки в коде и добавляет проверку
полного известного набора. Только успешный CI подтвердит выполнение новых
C++-тестов; только повторный аудит реального XEX подтвердит PASS на этом файле.
Поведение всех функций, первый кадр, сохранения и прохождение — отдельные этапы.
Предупреждение о размере `.reloc` этим изменением не исправляется.
